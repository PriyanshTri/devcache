## 2024-06-26 - Stateful icon-only action buttons accessibility
**Learning:** Stateful icon-only action buttons (e.g., copy buttons, favorite toggles) must dynamically update both their aria-label and title attributes to reflect their current status (e.g., changing from 'Copy item content' to 'Copied').
**Action:** When implementing interactive icon-only elements, ensure ARIA attributes dynamically update when state changes to provide accurate feedback for all users.
